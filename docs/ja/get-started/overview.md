# 概要

mare は小さな Rust コアと Lua 5.5 プラグインで構成されるエージェントハーネスです。組み込みプラグインはすべて読んで、包んで、置き換えられます。

## mare とは

Rust コアは OS サンドボックス、永続ストレージ、Lua ランタイム、およびターミナル描画 (`mare-tui` / `mare-cli`) を担います。エージェントループ、ツール、モデルプロバイダー、コンパクション、権限ルール、および UI コンポーネント・テーマ・ステータスラインは組み込み Lua プラグインとしてバイナリに同梱されています。

![mare レイヤー構成図](../../assets/diagrams/architecture.svg)

| レイヤー | 記述言語 | 役割 |
| --- | --- | --- |
| コア | Rust | プラグインカーネル (イベント・サービス・ライフサイクル・ウォッチドッグ)、Lua ランタイム、OS サンドボックス、セッション保存、ファイルスナップショット、プロジェクト信頼、TUI レンダラー (`mare-tui`)、mare RPC 3.0 (JSON-RPC 2.0) |
| 組み込みプラグイン | Lua 5.5 | エージェントループ、ツール、プロバイダー、コンパクション、権限、承認、セッション、スラッシュコマンド、UI コンポーネント、テーマ、ステータスライン、レビュー、バックグラウンドジョブ、MCP クライアント |
| あなたのプラグイン | Lua 5.5 | `init.lua`、`~/.config/mare/plugins/`、`.mare/plugins/`、またはパッケージからの追加・上書き |

`mare runtime` を実行すると、組み込みプラグインの読み取り専用ソース (`agent.lua`、`tools.lua` など) と Lua 型定義のディレクトリが表示されます。

## パッチではなく置き換え

- オプション変更: `mare.plugin("tools", { bash_timeout_ms = 120000 })`
- `init.lua` からツール、スラッシュコマンド、キーバインド、スタイルを追加。
- 同名で `override = true` のプラグインで組み込みを置き換え (`/plugins` に上書き関係を表示)。

コアの境界:

- コアの安全境界: サンドボックス、ファイル・プロセス権限チェック、耐クラッシュ JSONL 書き込み、プロジェクト信頼、Lua ウォッチドッグ (`watchdog_ms`) は Rust 側で強制します。エージェントループを置き換えても、権限プラグインと保護されたツールパイプライン経由の呼び出しでは維持されます。
- 信頼済みプラグイン境界: プラグインは信頼されたコードとして動きます。`permissions` を無効化・置換するプラグインや、ツール呼び出し外でプリミティブを直接呼ぶ処理は制限されません。
- 障害分離: 任意のプラグインやパッケージの失敗は警告を報告してスキップされます。必須サービス、`required = true` のプラグイン、または必須パッケージの失敗は、修正して `/reload` するまでリクエストをブロックします。`/plugins` でトレースバックを確認できます。

## 同じ機能、5 つのフロントエンド

| フロントエンド | 起動コマンド | 用途 |
| --- | --- | --- |
| ターミナル UI | `mare` | 対話型ターミナルセッション (`mare-tui` / `mare-cli`) |
| ヘッドレス | `mare -p "prompt"` / `mare --json "prompt"` | スクリプト・CI 向けの単発実行と JSON ストリーム |
| stdio RPC | `mare --rpc` | mare RPC 3.0 (JSON-RPC 2.0) による任意言語からの制御 (`mare rpc schema`) |
| HTTP / WebSocket リスナー | `mare --web` | 認証付き HTTP ルートと WebSocket RPC (Web UI はプラグインが提供) |
| ACP | `mare acp` | エディター連携 (Agent Client Protocol) |

プロセス内 Lua (`init.lua` とプラグイン) は、すべてのフロントエンドが共有する拡張レイヤーに位置します。
