# 対話型インターフェース

mare のターミナル UI の仕組みを説明します。入力エディター、キーバインド、スラッシュコマンド、ファイルのメンション、シェルコマンド、キューに入れたメッセージ、トランスクリプト、通知を扱います。

mare は代替スクリーンではなく、ターミナルのメイン画面で動作します。完了した出力 (メッセージ、ツール呼び出し、差分) はターミナルの通常のスクロールバックに書き込まれるため、スクロール、検索、コピーにはターミナル自身の機能を使えます。ライブなのは画面の下部だけです。ストリーミング中の応答、ウィジェット、入力ボックス、ステータスバーです。次のように起動します。

```sh
mare                       # new session
mare "explain this repo"   # new session, first prompt already sent
mare -c                    # continue the last session in this directory
```

## 入力エディター

プロンプトを入力して Enter で送信します。

| キー | 動作 |
| --- | --- |
| `Enter` | 送信します。Enter の直前に末尾の `\` があると、代わりに改行を挿入します。 |
| `Shift+Enter`、`Ctrl+J` | 改行を挿入します。 |
| `Left` / `Right`、`Ctrl+B` / `Ctrl+F` | 1 文字ずつ移動します。 |
| `Alt+Left` / `Alt+Right`、`Alt+B` / `Alt+F` | 単語単位で移動します。 |
| `Home` / `End`、`Ctrl+A` / `Ctrl+E` | 行頭 / 行末に移動します。 |
| `Up` / `Down`、`Ctrl+P` / `Ctrl+N` | 行間を移動します。最初または最後の行では、プロンプト履歴をたどります。 |
| `Backspace`、`Ctrl+H`、`Delete`、`Ctrl+D` | 1 文字削除します。入力が空のときの `Ctrl+D` は終了します。 |
| `Ctrl+W`、`Alt+Backspace` | 前の単語を削除します。 |
| `Alt+D` | 次の単語を削除します。 |
| `Ctrl+U` / `Ctrl+K` | 行頭 / 行末まで切り取ります。 |
| `Ctrl+Y`、`Alt+Y` | 最後に切り取ったテキストを貼り付けます。以前の切り取りを順にたどります。 |
| `Ctrl+_` | 入力内で元に戻します。 |
| `Ctrl+G` | 外部エディターで入力を編集します。 |
| `Up` の後の `Ctrl+R` | プロンプト履歴を検索します。 |
| `Tab` | `@file` や `/command` を補完します。 |

大きな貼り付けは、入力内でプレースホルダーに折りたたまれ、送信時に展開されます。プロンプト履歴は `~/.local/state/mare/history.jsonl` (または `$XDG_STATE_HOME/mare` の下) に保存されます。

すべてのターミナルが `Shift+Enter` と `Alt+Enter` を区別して送るわけではありません。`/terminal-setup` を実行すると、お使いのターミナルを確認でき、直し方も表示されます。

### 外部エディター

`Ctrl+G` は入力をエディターに渡し、エディターが正常に終了すると結果を戻します。mare は `editor` オプション、次に `$VISUAL`、次に `$EDITOR`、最後に `vi` を使います。値には引数を含められます。例: `code --wait`。

```lua
-- ~/.config/mare/init.lua
mare.setup { editor = "nvim" }
```

### キーバインド

以下は既定のバインドです。入力が空のときに `?` を押すか、`/hotkeys` を実行すると、変更内容を含む現在の一覧が表示されます。

| キー | 動作 |
| --- | --- |
| `Esc` | エージェントを中断します。アイドル時に素早く 2 回押すと、巻き戻しピッカー (`/undo`) が開きます。 |
| `Ctrl+C` | メニューを閉じる、下書きを消去する、実行中の作業を中断する。アイドルで入力が空のときに 2 回押すと終了します。 |
| `Ctrl+D` | 入力が空のとき、終了します。 |
| `Ctrl+O` | ツール出力と思考の、コンパクト表示と展開表示を切り替えます。 |
| `Ctrl+T` | トランスクリプトビューを開きます。 |
| `Ctrl+S` | 入力を実行中のターンに送ります (steer)。 |
| `Alt+Enter` | 入力をフォローアップとしてキューに入れます。Windows ではこのキーは `Ctrl+Q` です。 |
| `Ctrl+V` | クリップボードの画像を貼り付けます。Windows ではこのキーは `Alt+V` です。 |
| `Ctrl+B` | 実行中のシェルコマンドをバックグラウンドに移します。何も実行していない場合は、カーソルを左に移動します。 |
| `Ctrl+L` | 画面を再描画します。 |
| `Ctrl+Z` | mare を一時停止します (`fg` で再開)。Windows では使えません。 |
| `Alt+S` | 選択モード: ライブ領域でマウスをドラッグしてテキストを選択し、離すとコピーされます。 |
| `?` | すべてのキーバインドを一覧表示します (入力が空のとき)。 |

これらはいずれも `mare.keymap.set` で再割り当てできます。[キーマップ](../configure/keymaps.md) を参照してください。

## スラッシュコマンド

入力の先頭で `/` を入力するとコマンド一覧が開き、矢印キーと `Tab` または `Enter` で選びます。`/help` はすべてのコマンドを一覧表示し、`/commands` は選んだものを実行できる一覧を開き、`/skills` は [スキル](context.md) について同じことをします。

| グループ | コマンド |
| --- | --- |
| セッション | `/new` (`/clear`)、`/resume` (`/sessions`)、`/name`、`/undo`、`/rewind`、`/fork`、`/clone`、`/tree`、`/compact`、`/export`、`/copy`、`/delete`、`/archive` |
| モデル | `/model`、`/effort`、`/login`、`/logout` |
| コンテキスト | `/init`、`/memory`、`/context`、`/add-dir` |
| 安全性 | `/permission` (`/permissions`)、`/yolo`、`/approval` |
| 確認 | `/status`、`/usage`、`/diff`、`/jobs`、`/mcp`、`/doctor`、`/config`、`/debug` |
| インターフェース | `/theme`、`/statusline`、`/hotkeys`、`/terminal-setup`、`/show-reasoning` |
| その他 | `/btw`、`/reload`、`/plugins`、`/exit` (`/quit`) |

コマンド一覧はどのプラグインが有効かによって変わります。お使いの環境での正確な一覧は `/help` で確認してください。完全なリファレンスは [スラッシュコマンド](../reference/slash-commands.md) にあります。

`init.lua` で `mare.command.alias("m", "model")` のように、独自の短い名前を追加できます。

## ファイルのメンション

`@` を入力してパスを入力し始めます。`Tab` は、作業ディレクトリと `/add-dir` で追加したディレクトリの下のファイルに対するあいまい一致で補完します。

```text
review @src/main.rs and compare it with @"docs/old design.md"
```

送信時に、mare はメンションされた各ファイルの内容をメッセージに添付します。空白を含むパスには `@"..."` を使います。ディレクトリは一覧として添付されます。添付できない参照は黙って捨てられることはなく、メッセージに理由 (存在しない、バイナリ、大きすぎる、拒否された) を示し、`read` ツールを案内する 1 行のメモが付きます。上限は 1 ファイルあたり 100 KiB、1 メッセージあたり 256 KiB で、どちらも `file-ref` プラグインのオプション (`max_bytes`、`max_total_bytes`) です。

```lua
mare.plugin("file-ref", { max_bytes = 200 * 1024 })
```

## シェルコマンド

入力が空のときに `!` を入力するとシェルモードに入り、続けてコマンドを入力します。

```text
!git status           runs the command; command and output go into the context
!!cat .env.example    runs the command; the output is shown but not added to the context
```

コマンドは、エージェントの `bash` ツールと同じ設定済みのシェルプログラムとプレリュードを使いますが、別のプロセスです。エージェントのシェルの状態 (作業ディレクトリやエクスポートした変数) は共有せず、`bash` ツールの `env_include` と `env_exclude` のポリシーも適用されません。`Esc` または `Ctrl+C` で中止できます。空のシェルプロンプトで Backspace を押すと、シェルモードを抜けます。エージェントがビジー状態の場合、出力は現在のツール結果の後に、steer のメッセージと同様に届けられます。モデルが見る出力は最大 2000 行または 50 KiB です (中間が切り詰められます)。

入力したシェルコマンドは承認の確認を通りません。あなた自身のコマンドだからです。ポリシーが対象とする範囲は [権限](permissions.md) を参照してください。

## エージェントの実行中に作業する

エージェントの作業中も入力を続けられます。

- `Enter` はメッセージをキューに入れます。メッセージはエージェントが受け取るまで入力欄の上に表示され、その後、通常のユーザーメッセージになります。
- `Ctrl+S` は steer します。テキストは実行中のターンに注入され、現在のツール呼び出しが終わった後に届けられます。
- `Alt+Enter` はメッセージをフォローアップとしてキューに入れます。ビジー中の `Enter` と同じです。
- 入力が空のとき、`Up` はキューにあるメッセージを選択します。`Up` と `Down` でメッセージ間を移動し、`Enter` は選択したメッセージを入力欄に読み込んで編集でき、`Delete` はそれを削除し、`Esc` は選択を終了します。
- メッセージがキューにある状態で、空の入力に対して `Enter` を押すと、メニューが開きます。今すぐ steer する、中断して送信する、キューに残す、です。
- `Esc` はターンを中断します。アイドルで入力が空のときに `Esc` を 2 回押すと、`/undo` ピッカーが開きます。`!cmd` の実行中に `Esc` を押すと、そのコマンドだけが中止されます。

`/btw <question>` は、会話に追加されず、入力欄の上のウィジェットで回答される補足の質問をします。

## トランスクリプトビュー

`Ctrl+T` は、ツール出力と思考を展開した状態で、完全なトランスクリプトをオーバーレイで開きます。キーは `less` と Vim に準じます。

| キー | 動作 |
| --- | --- |
| `j` / `Down`、`k` / `Up` | 1 行スクロールします。 |
| `Space`、`f`、`PageDown`、`b`、`PageUp` | 1 ページスクロールします。 |
| `g` / `Home`、`G` / `End` | 先頭 / 末尾に移動します。 |
| `/`、`n`、`N` | 検索、次の一致、前の一致。 |
| `y` | 読んでいる位置のメッセージをコピーします。 |
| `q`、`Ctrl+T` | 閉じます。 |
| `Esc`、`Ctrl+C` | 検索を解除し、次に閉じます。 |

`Ctrl+O` は、スクロールバックに確定済みのブロックとライブブロックの両方について、ツール出力と思考のコンパクト表示と展開表示をその場で切り替えます。

## 画像

`Ctrl+V` (Windows では `Alt+V`) は、クリップボードの画像を次のメッセージに添付します。画像プロトコル (Kitty、iTerm2、sixel) に対応したターミナルでは、貼り付けた画像とツールが返した画像がインラインで描画されます。それ以外では、トランスクリプトに `[image]` と表示されます。インライン描画の無効化やサイズの変更は、`images` プラグインのオプション `user`、`read`、`tools`、`max_rows`、`max_cols` で行います。

## ステータスライン

入力の下のバーには、権限モード、モデルと effort、コンテキストのゲージ、作業ディレクトリ、git ブランチとそのプルリクエスト (`gh` 経由)、変更されたファイル、コスト、クォータが表示されます。`/statusline` はセグメントを切り替え、その選択を `state.json` に保存します。代わりに独自のコマンドを実行するには、標準入力で JSON オブジェクトを受け取り、その最初の出力行を表示するコマンドを指定します。

```lua
mare.plugin("statusline", { command = "~/bin/sl" })
```

レイアウトとテーマは [UI](../configure/ui.md) を参照してください。

## 通知

5 秒以上かかったターンが終了したとき、または mare があなたの応答 (質問や承認) を待っているときに、ターミナルがフォーカスされていなければ、ターミナル通知 (OSC 9、777、99、またはベル) を送ります。`notify` プラグインで調整できます。

```lua
mare.plugin("notify", { min_turn_ms = 10000, only_unfocused = true })
-- or run a program with a JSON event on stdin:
mare.plugin("notify", { cmd = { "notify-send-mare" } })
```

`cmd` はヘッドレスと RPC モードでも実行されます。`enabled = false` を設定すると、プラグインを無効にします。
